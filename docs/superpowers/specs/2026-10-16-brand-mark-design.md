# Mac MCP brand mark: one monogram everywhere (#187, #204)

Date: 2026-10-16
Status: design approved in conversation (visual companion), written for review

## Goal

Mac MCP gets one recognizable mark. A single thin line draws an **M**. The browser Visual
Companion's pointer, turned upright, carries on the M's right leg. The mark is used on every
surface where the logo appears today: the app icon, the menu bar, the menu header, the Live
Island, the tour, the site, the social preview, the Remotion video (and so the README demo
video), the mobile page, the dashboard and the ChatGPT panel.

## Owner decisions

| Question | Choice |
|---|---|
| Mark | The thin single-line monogram with the modern pointer (Visual Companion pointer), everywhere |
| Pointer angle | 22°: its left edge carries on the M's right leg |
| Centring | The **M itself** is centred; the pointer hangs off its right leg |
| Colour | Champagne `#f1e7d2 → #b9a98a` on dark backgrounds, bronze `#9c8a66 → #6f5f42` on light ones; no orange, no violet |
| App icon (Dock, Finder, notifications) | Obsidian tile `#34363d → #111216` with the champagne mark |
| Menu header | The bare transparent mark, no tile |

Rejected along the way: the orange M (it reads as Gmail's M), the violet and indigo
palettes, the pointer-shaped mark, the two-arch "m", and a two-weight family.

## The mark

Master geometry, on a 64×64 grid, with the M centred at x = 32:

```
M:        M14 49 V15 L32 33 L50 15 V29          stroke, round caps and joins
pointer:  M3.4 3.2 23 11.2 14.6 14.4 11.3 23.2Z  rounded joins
          placed with translate(50 33.2) rotate(22) scale(0.8) translate(-3.4 -3.2)
```

Line weight is 4.2 at hero size. Small sizes get heavier versions so that the line never
drops below about 1.4 px:

| Size | Weight |
|---|---|
| ≥ 128 px | 4.2 |
| 64 px | 4.6 |
| 32 px | 5.0 |
| ≤ 20 px, and the menu bar | 5.6 |

The source files live in `assets/brand/`. They are hand-authored SVG with a `viewBox`. They
contain no scripts, external references, fonts or embedded images.

| File | What it is |
|---|---|
| `mark.svg` | Champagne, for dark backgrounds |
| `mark-bronze.svg` | Bronze, for light backgrounds |
| `mark-mono.svg` | `currentColor`, heavier stroke; for template and single-colour uses |
| `app-icon.svg` | 1024×1024 canvas. Apple's 824×824 rounded tile (radius 185) at a 100 px inset, obsidian gradient, faint inner highlight and soft shadow, the champagne mark at 68 % of the tile. Transparent outside the tile. |

`scripts/build_brand.py` (standard library plus `rsvg-convert` and `magick`, which are already
on the build Mac) renders every PNG below from these sources. `--check` fails when a generated
file differs from its source, so the outputs never drift.

## Menu bar states (#187)

The template image carries the state. Template images only have alpha, so states use alpha and
shape, never colour:

| State | Look |
|---|---|
| Server stopped | the mark at 40 % alpha |
| Running, idle | the mark |
| Agents or sessions working | the mark with a small filled dot at the top right; the existing `pulse` alternates the dot between filled and hollow |

The accessibility label is unchanged; it already speaks the state.

## Testing

- **`tests/test_brand_assets.py`:**
  - the SVGs parse and hold no `<script>`, `href` to anything external or `<image>`;
  - `build_brand.py --check` passes;
  - each PNG has its stated size and an alpha channel;
  - the menu bar PNGs are black-only (template);
  - every consumer references a file that exists.
- **Existing tests that pin the old icons are updated:** menu status surfaces, site, onboarding.
- **Native:**
  - `menu_app/build_app.sh /tmp/…` and `codesign --verify --deep --strict`;
  - install from the **source repo**, then check that the running binary is the new one;
  - capture the menu bar (light and dark, stopped, running and working), the menu header (dark and light), the Live Island, and the Dock and Finder icon.
- **Web:**
  - site preview through `build_site.py --offline`;
  - the mobile page, dashboard and ChatGPT panel rendered in a browser;
  - after the push, the live GitHub Pages site serves the new favicon, brand and OG image.
- **Video:** the render passes the export budgets; the poster and video show the new icon.

## Out of scope

- tarkan.cloud deployment (follow-up, owner's go-ahead).
- New wordmark or typography.
- Changing layouts to show the logo more.
- A release or a new signed checkpoint.
