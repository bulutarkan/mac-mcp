Let your AI apps use your Mac.

A local server and menu bar app that lets Claude, ChatGPT, Codex and other MCP apps work in your Mac's apps, files, terminal and browser, with approvals you control.

Download Mac MCP {{version}} View on GitHub

The package is for Apple Silicon on macOS 14 or later; the Terminal installer covers any Mac on macOS 13 or later. Open source under the MIT license, release {{release_id}}.

Works with Claude Desktop, Claude Code, ChatGPT, Codex, OpenCode and other MCP clients.

Forty seconds, six scenes.

Each scene below is a moment from the demo. Pick a time to play the video from there.

  1. Your AI can think. It can't use your Mac.

    Ask a chat app to summarize the PDFs in your Downloads folder and it tells you it can't open files. Mac MCP gives Claude, ChatGPT, Codex and other MCP apps your Mac's apps, files, terminal and browser.

  2. Connect the AI apps you already use.

    Claude Desktop, Claude Code, ChatGPT, Codex and OpenCode connect in one click from the menu bar app. ChatGPT reaches your Mac through a public endpoint you turn on, such as a Cloudflare Tunnel, so you can ask it from your phone too.

  3. See what it's doing.

    It works inside your apps: Notes, Finder and Mail through macOS Accessibility, using the same buttons and menus you do. The live island beside the notch shows the app in use, then a tick. It is optional and off by default.

  4. Visible, non-focus-stealing browser work.

    Forms, long pages and comment threads are handled in a Safari or Chrome tab while you keep typing elsewhere. The tab is framed so you can see what it touches.

  5. Hand off work. Get a report back.

    Delegate a task to a Codex, Claude Code or OpenCode agent and read a report of its steps and the files it changed. Scheduled Tasks run AI tasks and scripts on the schedule you set; tasks an AI app suggests wait for your approval.

  6. You stay in charge.

    Permission profiles decide which kinds of tools may run. Turn on Server Approval and risky actions, like sending an email, wait for your Allow Once or Block. Pause observation and Private mode are in Settings › Privacy.

What it promises, and what it doesn't.

Rules the server enforces

  • Permission profiles decide which kinds of tools may run. An allowed capability is not an approval prompt; Server Approval adds an Allow Once or Block answer for risky actions when you turn it on.
  • Pause observation, Private mode and never-observe lists for apps and sites, in Settings › Privacy.
  • The live island beside the notch is off by default.
  • Updates install only signed stable release checkpoints.

What Mac MCP is not

  • It is not a sandbox. It acts with your macOS user's permissions.
  • Localhost is machine-local transport, not same-user isolation.
  • What your AI app reads through Mac MCP is sent to that app's provider.
  • Browser work is visible on screen, not hidden.
  • The package is not notarized yet, so macOS asks you to choose Open Anyway the first time.
