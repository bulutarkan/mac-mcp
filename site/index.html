How it works

Apps, files, terminal

It works inside your apps.

Your AI app opens Notes, looks through a folder in Finder or drafts a reply in Mail through macOS Accessibility, using the same buttons and menus you do. Files and the terminal are there too.

Safari and Chrome

It browses where you can see it.

Visible, non-focus-stealing browser automation: forms, long pages and comment threads are handled in a tab while you keep using your Mac, and the tab is framed so you can see what it touches.

Agents and schedules

It hands off work and reports back.

Delegate a task to a Codex, Claude Code or OpenCode agent and read a report of what it did. Scheduled Tasks (experimental) run AI tasks and scripts on the schedule you set.

What people do with it

Ask ChatGPT from your phone

Talk to ChatGPT while you are away and let it work on the Mac at your desk. ChatGPT reaches your Mac through a public endpoint you turn on, such as a Cloudflare Tunnel.

Build with Claude Code

Claude Code runs your tests, reads the failing page in the browser and checks the app it just changed, without leaving the terminal.

Hand a job to Codex

Ask for a release checklist or a cleanup across the repo; a Codex agent works in its own folder and leaves a report with its steps and the files it changed.

Get a summary every weekday

A scheduled task runs at 08:30 and sends a notification when its report is ready. Tasks an AI app suggests wait for your approval. Experimental.

You stay in charge.

Rules the server enforces

  • Permission profiles decide which kinds of tools may run. An allowed capability is not an approval prompt; Server Approval adds an Allow Once or Block answer for risky actions when you turn it on.
  • Pause observation, Private mode and never-observe lists for apps and sites, in Settings › Privacy.
  • The live island beside the notch is off by default.
  • Updates install only signed stable release checkpoints.

What Mac MCP is not

  • It is not a sandbox. It acts with your macOS user's permissions.
  • Localhost is machine-local transport, not same-user isolation.
  • What your AI app reads through Mac MCP is sent to that app's provider.
  • Browser work is visible on screen, not hidden.
  • The package is not notarized yet, so macOS asks you to choose Open Anyway the first time.
