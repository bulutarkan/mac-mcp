# Code of Conduct

Mac MCP is an open-source project. Participation should stay respectful, technical, and constructive.

## Expected behavior

When participating in issues, pull requests, reviews, discussions, or other project spaces:

- treat other people with respect;
- criticize ideas and code without attacking the person;
- keep feedback specific, useful, and relevant to the project;
- assume good faith while still asking for evidence and reproducible behavior;
- respect privacy and do not publish another person's personal information;
- follow responsible disclosure practices for security issues.

## Unacceptable behavior

The following are not acceptable:

- harassment, threats, intimidation, or personal attacks;
- discriminatory or demeaning language;
- unwanted sexual attention or sexualized harassment;
- doxxing or publishing private information without permission;
- deliberate disruption, spam, or repeated off-topic behavior;
- encouraging others to violate these rules.

## Enforcement

Project maintainers may edit or remove comments, issues, pull requests, or other contributions that violate this policy. Depending on severity or repeated behavior, maintainers may issue a warning, restrict participation, or permanently block a participant from project spaces.

Decisions should be based on the behavior in question, not disagreement over technical opinions.

## Reporting conduct problems

If a conduct issue can be handled safely in public, flag it to the maintainer in the relevant project thread. For harassment, privacy concerns, threats, or other sensitive situations, open only a minimal issue asking the maintainer for a private contact path and do not post sensitive details publicly.

Security vulnerabilities should be reported through the process in [SECURITY.md](SECURITY.md), not through a conduct report.

## Scope

This policy applies to official project spaces and to situations where someone is clearly representing the project.

The goal is simple: make it possible for people to disagree strongly about software while still treating each other decently.
